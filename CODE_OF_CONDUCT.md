# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

Be respectful and constructive. Harassment, personal attacks, and
discriminatory language are not tolerated in issues, pull requests, or any
other project space.

Report unacceptable behavior to orbismartyrer@gmail.com. Reports are handled
confidentially. Maintainers may remove comments, close discussions, or ban
contributors who violate this code.
